# Language

- Use English by default for code identifiers, comments, docstrings, documentation, issues, pull requests, commit messages, and other project artifacts.
- Apply this preference to future work even when the user's request is written in Hungarian, unless the user explicitly requests another language.

# Git operations

- Commit and push only when the user explicitly requests the specific operation for the current changes.
- A request to fix code, run tests, or complete a task does not by itself authorize a commit or push.
- Authorization to commit or push for an earlier task does not automatically apply to a later task.
- Without an explicit request, leave changes in the working directory without committing or pushing.
